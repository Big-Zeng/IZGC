# 交互式聚类分析系统使用说明

## 系统概述

这是一个基于Web的交互式客户聚类分析系统，允许用户在浏览器中动态调整聚类参数，实时查看聚类结果和评价指标。

## 系统架构

```
┌─────────────────┐         ┌─────────────────┐
│   前端页面      │ ◄─────► │  Flask后端      │
│ (HTML/JS/百度   │  HTTP   │  (Python)       │
│  地图API)       │  API    │                 │
└─────────────────┘         └─────────────────┘
                                    │
                                    ▼
                            ┌─────────────────┐
                            │ 聚类算法        │
                            │ (ContourBased   │
                            │  ClusteringZ22) │
                            └─────────────────┘
```

## 安装依赖

在运行系统之前，请确保安装以下Python包：

```bash
pip install flask flask-cors numpy scipy scikit-learn shapely matplotlib
```

## 启动步骤

### 方法1：使用批处理文件（Windows）

1. 双击运行 `启动交互式聚类服务.bat`
2. 等待服务器启动（看到 "Running on http://0.0.0.0:5000" 提示）
3. 打开浏览器访问：`http://localhost:5000`

### 方法2：手动启动

1. 打开命令行，进入 `map_visualization` 目录
2. 运行命令：
   ```bash
   python clustering_server.py
   ```
3. 打开浏览器访问：`http://localhost:5000`

## 使用界面

### 左侧参数面板

#### 1. 网格大小 (grid_size)
- **范围**: 0.01 - 0.2
- **默认值**: 0.05
- **说明**: 控制虚拟点网格的密集程度
- **效果**: 
  - 值越小 → 网格越密集 → 计算量越大 → 聚类更精细
  - 值越大 → 网格越稀疏 → 计算量越小 → 聚类更粗糙

#### 2. 最大缓冲距离 (max_buffer_distance)
- **范围**: 1 - 20
- **默认值**: 5
- **说明**: 等值线区域向外扩展的最大步数
- **效果**:
  - 值越小 → 簇边界更紧密 → 可能产生更多小簇
  - 值越大 → 簇边界更宽松 → 簇的覆盖范围更大

#### 3. 最小簇大小 (min_cluster_size)
- **范围**: 1 - 50
- **默认值**: 10
- **说明**: 小于此值的簇会被合并到最近的大簇中
- **效果**:
  - 值越小 → 允许更多小簇存在
  - 值越大 → 强制合并小簇，减少簇的数量

### 右侧地图显示

- **彩色圆点**: 客户位置，不同颜色代表不同的簇
- **点击圆点**: 查看客户详细信息和所属簇
- **鼠标悬停**: 显示客户名称和簇编号
- **右下角图例**: 显示各簇的颜色和点数
- **左上角信息框**: 显示聚类统计信息

### 聚类结果面板

显示两部分信息：

#### 📊 聚类结果
- **簇数**: 发现的聚类簇数量
- **噪声点**: 未分配到任何簇的点数（通常为0）
- **有效点数**: 成功分配到簇的点数

#### 📈 评价指标

1. **轮廓系数 (Silhouette Score)**
   - 范围: [-1, 1]
   - 评价标准:
     - > 0.7: 优秀（蓝色显示）
     - 0.5 - 0.7: 良好（绿色显示）
     - < 0.5: 一般
   - 含义: 衡量簇内紧密度和簇间分离度

2. **CH指数 (Calinski-Harabasz Index)**
   - 范围: [0, +∞)
   - 含义: 值越大，簇间分离度越好

3. **DB指数 (Davies-Bouldin Index)**
   - 范围: [0, +∞)
   - 评价标准:
     - < 0.5: 优秀（蓝色显示）
     - 0.5 - 1.0: 良好
     - > 1.0: 一般
   - 含义: 值越小，聚类质量越高

4. **簇内误差 (Inertia)**
   - 范围: [0, +∞)
   - 含义: 值越小，簇内点越紧密

## 使用流程

1. **调整参数**: 使用滑块调整三个聚类参数
2. **开始聚类**: 点击"开始聚类分析"按钮
3. **等待计算**: 按钮显示"聚类中..."，等待几秒到几十秒
4. **查看结果**: 
   - 地图上显示彩色聚类结果
   - 左侧显示评价指标
   - 点击地图上的点查看详情
5. **调整优化**: 根据结果调整参数，重新聚类

## 参数调优建议

### 场景1：簇数太多，想减少簇数
- ✓ 增大 `max_buffer_distance`（如 5 → 10）
- ✓ 增大 `min_cluster_size`（如 10 → 20）
- ✓ 增大 `grid_size`（如 0.05 → 0.1）

### 场景2：簇数太少，想增加簇数
- ✓ 减小 `max_buffer_distance`（如 5 → 3）
- ✓ 减小 `min_cluster_size`（如 10 → 5）
- ✓ 减小 `grid_size`（如 0.05 → 0.03）

### 场景3：有很多小簇（噪声点）
- ✓ 增大 `min_cluster_size`（强制合并小簇）
- ✓ 增大 `max_buffer_distance`（扩大簇的覆盖范围）

### 场景4：追求高质量聚类
- ✓ 观察轮廓系数，调整参数使其 > 0.5
- ✓ 观察DB指数，调整参数使其 < 1.0
- ✓ 多次尝试不同参数组合，比较评价指标

## 性能说明

- **数据量**: 8,489 个客户点

## 常见问题

### Q1: 服务器启动失败
**A**: 检查是否安装了所有依赖包：
```bash
pip install flask flask-cors numpy scipy scikit-learn shapely matplotlib
```

### Q2: 浏览器无法访问
**A**: 
- 确认服务器已启动（命令行显示 "Running on..."）
- 检查防火墙是否阻止了5000端口
- 尝试访问 `http://127.0.0.1:5000` 而不是 `localhost`

### Q3: 聚类计算很慢
**A**: 
- 增大 `grid_size` 参数（如 0.05 → 0.1）
- 减小 `max_buffer_distance` 参数
- 这是正常现象，8000+点的聚类需要一定时间

### Q4: 地图不显示
**A**: 
- 检查是否配置了百度地图AK（在HTML文件中）
- 检查网络连接是否正常
- 打开浏览器控制台查看错误信息

### Q5: 聚类结果不理想
**A**: 
- 尝试不同的参数组合
- 参考"参数调优建议"部分
- 观察评价指标，选择轮廓系数较高的参数

## 技术特点

1. ✓ **实时交互**: 参数调整后立即重新聚类
2. ✓ **可视化**: 百度地图直观显示聚类结果
3. ✓ **评价指标**: 多种无监督评价指标
4. ✓ **非交互模式**: 后端聚类不显示matplotlib窗口
5. ✓ **小簇合并**: 自动合并小于阈值的簇
6. ✓ **无噪声点**: 所有点都会被分配到簇中
