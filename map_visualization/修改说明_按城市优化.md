# optimize_grid_size_by_area.py 修改说明

## 最新修改（2025-01-04）

### ✅ 添加坐标转换和归一化功能

**新增功能**:
1. **经纬度 → 平面坐标转换** - 使用简化墨卡托投影
2. **平面坐标归一化** - 归一化到 [0, 100] 范围

**转换流程**:
```
经纬度 (度) → 平面坐标 (公里) → 归一化坐标 [0, 100]
```

**新增函数**:
- `lonlat_to_xy(lon, lat, lon_ref, lat_ref)` - 经纬度转平面坐标
- `normalize_coordinates(coords)` - 坐标归一化

**实际效果**（长沙市示例）:
- 原始: 经度 [112.36°, 114.09°], 纬度 [28.02°, 28.51°]
- 平面: X [-62.08, 107.87] km, Y [-20.62, 34.06] km
- 归一化: X [0, 100], Y [0, 100]
- 缩放比例: 1 单位 ≈ 1.7 km (X) / 0.55 km (Y)

**参数含义变化**:
- `grid_size = 1.0` 现在对应约 1-2 公里的实际距离
- 密度半径 `5` 对应约 2.7-8.5 公里

详见: `坐标转换说明.md`

## 修改内容（2025-01-04）

已将脚本从**按区域优化**改为**按城市优化**。

## 主要变更

### 1. 配置参数
**修改前**:
```python
TARGET_CITY = ""            # 指定城市名称
TARGET_AREA = ""            # 指定区域名称
MIN_POINTS = 50             # 最少点数（少于此值的区域跳过）
```

**修改后**:
```python
TARGET_CITY = ""            # 指定城市名称，留空处理所有城市
MIN_POINTS = 50             # 最少点数（少于此值的城市跳过）
```

### 2. 数据源
**修改前**: 使用 `index_data['city_areas']` (区域级数据)  
**修改后**: 使用 `index_data['cities']` (城市级数据)

### 3. 输出文件命名
**修改前**: `{城市}_{区域}.png`  
**修改后**: `{城市}.png`

### 4. 报告内容
**修改前**: 
- 表格包含"城市"和"区域"两列
- 统计"区域数量"

**修改后**: 
- 表格只包含"城市"列
- 统计"城市数量"

## 注意事项

1. **数据粒度**: 现在是城市级别，不再是区域级别
2. **客户数量**: 城市级数据包含更多客户，计算时间会更长
3. **MIN_POINTS**: 默认50，可根据需要调整
4. **输出文件**: 图表文件名只包含城市名称
