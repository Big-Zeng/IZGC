# 坐标转换和归一化说明

## 📍 功能概述

`optimize_grid_size_by_area.py` 现在包含完整的坐标转换流程：

1. **经纬度 → 平面坐标** - 使用简化墨卡托投影
2. **平面坐标 → 归一化坐标** - 归一化到 [0, 100] 范围

## 🔄 转换流程

### 步骤1: 经纬度转换为平面坐标

使用简化的墨卡托投影，将经纬度（度）转换为平面坐标（公里）。

**公式**:
```
x = R × (lon - lon_ref) × cos(lat_ref)
y = R × (lat - lat_ref)
```

其中:
- `R = 6371.0` km（地球半径）
- `lon_ref, lat_ref` 是参考点（区域中心）
- 所有角度先转换为弧度

**特点**:
- 保持相对距离关系
- 单位为公里，便于理解
- 适用于小范围区域（如一个城市）

### 步骤2: 归一化到 [0, 100] 范围

将平面坐标归一化到 [0, 100] 范围，便于聚类算法处理。

**公式**:
```
x_norm = (x - x_min) / (x_max - x_min) × 100
y_norm = (y - y_min) / (y_max - y_min) × 100
```

**特点**:
- 统一坐标尺度
- 便于设置 grid_size 参数
- 保持数据的相对位置关系

## 📊 实际案例：长沙市

### 原始数据
- 客户数: 3229
- 经度范围: [112.360465°, 114.094707°]
- 纬度范围: [28.017865°, 28.509590°]

### 转换结果

**参考点（区域中心）**:
- 经度: 112.993974°
- 纬度: 28.203269°

**平面坐标范围**:
- X: [-62.080, 107.865] km
- Y: [-20.616, 34.061] km
- X跨度: 169.944 km
- Y跨度: 54.677 km

**归一化后范围**:
- X: [0.00, 100.00]
- Y: [0.00, 100.00]

**缩放比例**:
- 1 单位 = 1.699 km (X方向)
- 1 单位 = 0.547 km (Y方向)

## 🎯 grid_size 参数的实际含义

归一化后，grid_size 参数的实际物理意义：

| grid_size | 长沙市实际距离 (X方向) | 长沙市实际距离 (Y方向) |
|-----------|----------------------|----------------------|
| 0.01 | 17 米 | 5.5 米 |
| 0.05 | 85 米 | 27 米 |
| 0.1 | 170 米 | 55 米 |
| 0.5 | 850 米 | 274 米 |
| 1.0 | 1.7 公里 | 547 米 |
| 5.0 | 8.5 公里 | 2.7 公里 |

**注意**: 不同城市的缩放比例不同，实际距离会有差异。

## 💡 参数设置建议

### 基于归一化坐标

推荐的 grid_size 范围（归一化坐标）:
- **密集城区**: 0.5 - 2.0
- **一般城区**: 1.0 - 5.0
- **稀疏郊区**: 2.0 - 10.0

### 基于实际距离

如果想基于实际距离设置参数：

1. 运行脚本查看缩放比例
2. 计算 grid_size = 目标距离(km) / 缩放比例(km/单位)

**示例**（长沙市）:
- 想要 1 公里的网格 → grid_size ≈ 1.0 / 1.699 ≈ 0.59
- 想要 500 米的网格 → grid_size ≈ 0.5 / 1.699 ≈ 0.29

## 📝 代码示例

### 完整转换流程

```python
import numpy as np

# 1. 读取经纬度数据
lonlat_coords = np.array([[client['lon'], client['lat']] for client in clients])

# 2. 计算参考点（区域中心）
lon_ref = np.mean(lonlat_coords[:, 0])
lat_ref = np.mean(lonlat_coords[:, 1])

# 3. 转换为平面坐标
xy_coords = np.array([lonlat_to_xy(lon, lat, lon_ref, lat_ref) 
                      for lon, lat in lonlat_coords])

# 4. 归一化到 [0, 100]
coords_norm, scale_info = normalize_coordinates(xy_coords)

# 5. 使用归一化坐标进行聚类
combined_data = [(coords_norm[i, 0], coords_norm[i, 1], density[i], i) 
                 for i in range(len(coords_norm))]
```

## ✅ 优势

1. **物理意义明确**: 坐标单位是公里，易于理解
2. **统一尺度**: 归一化后便于设置参数
3. **保持关系**: 保持点之间的相对距离和位置关系
4. **适用性强**: 适用于不同大小的城市区域

## ⚠️ 注意事项

1. **投影误差**: 简化墨卡托投影在大范围区域会有误差，但对于城市级别（几十到几百公里）误差可忽略
2. **各向异性**: X和Y方向的缩放比例可能不同，这是正常的（取决于区域的形状）
3. **参考点选择**: 使用区域中心作为参考点，确保坐标分布均匀
