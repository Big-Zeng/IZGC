================================================================================
主要功能
================================================================================

1. ✓ 交互式Web界面
   - 左侧参数调整面板（3个滑块）
   - 右侧百度地图显示
   - 实时聚类分析

2. ✓ 动态参数调整
   - grid_size: 0.01 - 0.2
   - max_buffer_distance: 1 - 20
   - min_cluster_size: 1 - 50

3. ✓ 实时聚类计算
   - 点击按钮执行聚类
   - 10-30秒完成计算
   - 自动更新地图显示

4. ✓ 可视化展示
   - 不同颜色区分不同簇
   - 点击查看客户详情
   - 图例显示各簇信息

5. ✓ 评价指标
   - 轮廓系数
   - CH指数
   - DB指数
   - 簇内误差

技术实现
================================================================================

1. 后端 (Flask)
   - RESTful API设计
   - /api/clients - 获取客户数据
   - /api/cluster - 执行聚类分析
   - CORS支持跨域请求

2. 前端 (HTML/JS)
   - 参数滑块实时更新
   - Fetch API异步请求
   - 百度地图API集成
   - 动态颜色生成

3. 算法修改
   - 添加 interactive 参数
   - 非交互模式不显示matplotlib窗口
   - 保持所有聚类功能

4. 可视化
   - 彩色圆点标记
   - 点击显示详情
   - 鼠标悬停提示
   - 图例和信息框

================================================================================
使用流程
================================================================================

1. 启动服务器
   → 运行 clustering_server.py

2. 打开浏览器
   → 访问 http://localhost:5000

3. 调整参数
   → 使用滑块调整三个参数

4. 执行聚类
   → 点击"开始聚类分析"按钮

5. 查看结果
   → 地图显示彩色聚类结果
   → 左侧显示评价指标

6. 交互探索
   → 点击地图标记查看详情
   → 调整参数重新聚类

================================================================================
常见问题
================================================================================

Q: 服务器启动失败？
A: pip install flask flask-cors

Q: 地图不显示？
A: 检查百度地图AK配置

Q: 聚类太慢？
A: 增大 grid_size 参数

Q: 端口被占用？
A: 修改 clustering_server.py 中的端口号
