# 快速启动指南

## 🚀 解决CORS跨域问题

由于浏览器安全策略，直接双击HTML文件打开会遇到CORS跨域错误。

### ✅ 推荐方法：使用本地服务器

#### Windows用户（最简单）
1. 双击 `启动地图服务器.bat` 文件
2. 浏览器会自动打开地图
3. 完成！

#### 所有用户
```bash
# 在map_visualization文件夹中运行
python start_server.py
```

服务器会：
- 启动在 http://localhost:8000
- 自动打开浏览器
- 显示百度地图

### 📋 访问地址

服务器启动后，可以访问：
- 百度地图：http://localhost:8000/client_map_baidu.html
- Leaflet地图：http://localhost:8000/client_map_leaflet.html

### ⚠️ 注意事项

1. **百度地图需要AK**
   - 打开 `client_map_baidu.html`
   - 找到 `YOUR_BAIDU_MAP_AK`
   - 替换为您的百度地图密钥
   - 申请地址：https://lbsyun.baidu.com/apiconsole/key

2. **Leaflet地图无需密钥**
   - 直接可用
   - 使用OpenStreetMap底图

3. **停止服务器**
   - 按 `Ctrl+C` 停止服务器
   - 或关闭命令行窗口

### 🔧 端口被占用？

如果8000端口被占用，修改 `start_server.py` 中的 `PORT` 变量：

```python
PORT = 8001  # 改为其他端口
```

### 📱 其他设备访问

如果想在手机或其他设备上查看：

1. 查看电脑IP地址（如：192.168.1.100）
2. 在其他设备浏览器访问：http://192.168.1.100:8000/client_map_baidu.html
3. 确保设备在同一局域网

### ❓ 常见问题

**Q: 为什么不能直接双击HTML文件？**
A: 浏览器的CORS安全策略限制了file://协议访问外部资源。

**Q: 服务器启动失败？**
A: 检查Python是否安装，端口是否被占用。

**Q: 地图显示空白？**
A: 检查网络连接，确认已配置百度地图AK（如使用百度地图）。
