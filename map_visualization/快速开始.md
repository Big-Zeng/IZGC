# 🚀 交互式聚类分析 - 快速开始

## 一键启动

### Windows用户
双击运行：`启动交互式聚类服务.bat`

### 所有用户
```bash
cd map_visualization
python clustering_server.py
```

## 访问地址

打开浏览器访问：**http://localhost:5000**

## 使用步骤

1. **调整参数** - 使用左侧滑块调整三个参数
2. **点击聚类** - 点击"开始聚类分析"按钮
3. **查看结果** - 地图显示彩色聚类结果，左侧显示评价指标
4. **点击查看** - 点击地图上的点查看客户详情

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| grid_size | 0.05 | 网格大小，越小越精细 |
| max_buffer_distance | 5 | 缓冲距离，越大簇越大 |
| min_cluster_size | 10 | 最小簇大小，小簇会被合并 |

## 评价指标

- **轮廓系数**: > 0.5 为良好，> 0.7 为优秀
- **DB指数**: < 1.0 为良好，< 0.5 为优秀
- **CH指数**: 越大越好

## 常见问题

**Q: 服务器启动失败？**  
A: 运行 `pip install flask flask-cors`

**Q: 地图不显示？**  
A: 检查百度地图AK配置（在HTML文件中）

**Q: 聚类太慢？**  
A: 增大 grid_size 参数（如 0.05 → 0.1）
