## 📄 文件格式

### JSON格式

每个JSON文件包含该城市/区域的所有客户信息：

```json
[
  {
    "id": "客户编码",
    "name": "客户名称",
    "lon": 112.9388,
    "lat": 28.2282,
    "degree": "1",
    "city": "长沙市",
    "area": "岳麓区",
    "street": "详细地址",
    "province": "湖南省"
  },
  ...
]
```

### CSV格式

每个CSV文件包含该城市/区域的客户坐标和基本信息：

```csv
lon,lat,id,name,degree,city,area,street
112.9388,28.2282,客户编码,客户名称,1,长沙市,岳麓区,"详细地址"
...
```

**用途**: CSV文件可以直接用于聚类算法输入。

## 🔧 使用CSV文件进行聚类

CSV文件可以直接用于聚类算法：

```python
import pandas as pd
import numpy as np

# 读取CSV文件
df = pd.read_csv('client_data_by_city/长沙市.csv')

# 提取坐标和密度数据
coords = df[['lon', 'lat']].values

# 计算密度（示例）
from scipy.spatial import cKDTree
tree = cKDTree(coords)
density = np.array([len(tree.query_ball_point(p, 0.1)) for p in coords])

# 准备聚类数据
combined_data = []
for i, row in df.iterrows():
    combined_data.append((
        row['lon'],
        row['lat'],
        density[i],
        i
    ))

# 使用聚类算法
import sys
sys.path.append('..')
import ContourBasedClusteringWithoutZ22_map as ContourClustering

cluster = ContourClustering.ContourBasedClusteringWithoutZ(
    combined_data,
    grid_size=0.05,
    max_buffer_distance=5,
    min_cluster_size=10,
    interactive=False
)

cluster.perform_clustering()
labels = cluster.get_predicted_labels()

print(f"聚类结果: {len(set(labels))} 个簇")
```

## 📝 注意事项

1. **数据完整性**: 部分客户可能缺少城市或区域信息（标记为"未知"）
2. **坐标系统**: 所有坐标为WGS84坐标系（标准GPS坐标）
3. **文件编码**: 所有文件使用UTF-8编码
4. **CSV格式**: 地址字段使用双引号包裹，避免逗号冲突
