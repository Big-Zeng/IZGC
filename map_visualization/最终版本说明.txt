================================================================================
技术实现
================================================================================

【后端】
  - 算法: ContourBasedClusteringWithoutZ22_map.py
  - 返回: labels + contour_polygons
  - 格式: {cluster_id, polygon, center, point_count}

【前端】
  - 地图: 百度地图 JavaScript API v3.0
  - 多边形: BMap.Polygon()
  - 点标记: BMap.Circle()
  - 坐标: 自动转换 WGS84 → BD09

【数据流】
  后端聚类 → 提取多边形 → JSON返回 → 前端绘制

================================================================================
常见问题
================================================================================

Q1: 地图不显示？
A: 配置百度地图AK，替换 YOUR_BAIDU_MAP_AK

Q2: 等值线不显示？
A: 检查浏览器控制台，确认 contour_polygons 数据

Q3: 坐标位置不对？
A: 百度地图会自动转换WGS84坐标，无需手动处理

Q4: 颜色都一样？
A: 检查 labels 数据，刷新页面重试

Q5: 多边形形状奇怪？
A: 调整 grid_size 参数（0.05 → 0.1）

  - 边界太复杂: 增大 grid_size
  - 簇太多: 增大 max_buffer_distance
  - 有很多小簇: 增大 min_cluster_size
