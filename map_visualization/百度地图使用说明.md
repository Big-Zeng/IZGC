# 百度地图版本使用说明

## 文件说明

- `client_map_baidu.html` - 百度地图版本的客户分布地图

## 使用步骤

### 1. 申请百度地图API密钥（AK）

1. 访问百度地图开放平台：https://lbsyun.baidu.com/
2. 注册/登录账号
3. 进入控制台：https://lbsyun.baidu.com/apiconsole/key
4. 创建应用，选择"浏览器端"
5. 获取AK（密钥）

### 2. 配置密钥

打开 `client_map_baidu.html` 文件，找到这一行：

```html
<script type="text/javascript" src="https://api.map.baidu.com/api?v=3.0&ak=YOUR_BAIDU_MAP_AK"></script>
```

将 `YOUR_BAIDU_MAP_AK` 替换为您申请的密钥：

```html
<script type="text/javascript" src="https://api.map.baidu.com/api?v=3.0&ak=您的密钥"></script>
```

### 3. 打开地图

**方法1：使用本地服务器（推荐）**

由于浏览器的CORS安全策略，直接双击HTML文件可能会报错。推荐使用本地服务器：

```bash
# 在map_visualization文件夹中运行
python start_server.py
```

或者直接双击 `启动地图服务器.bat` 文件（Windows）

服务器会自动打开浏览器访问：http://localhost:8000/client_map_baidu.html

**方法2：直接打开（可能有CORS问题）**

如果遇到CORS错误，请使用方法1。

## 坐标系统说明

### 百度地图坐标系（BD-09）
百度地图使用自己的坐标系统（BD-09），与GPS坐标（WGS-84）和国测局坐标（GCJ-02）不同。

**当前数据**：
- 数据来源：Client_t.sql
- 坐标系统：可能是GCJ-02（火星坐标系）
- 显示效果：在百度地图上可能有轻微偏移

### 如果需要坐标转换

如果发现地图上的点位置不准确，可能需要进行坐标转换：

1. **GCJ-02 → BD-09**（火星坐标 → 百度坐标）
2. **WGS-84 → BD-09**（GPS坐标 → 百度坐标）

可以使用百度地图API的坐标转换服务：
```javascript
// 示例：GCJ-02转BD-09
var convertor = new BMap.Convertor();
var pointArr = [new BMap.Point(lng, lat)];
convertor.translate(pointArr, 1, 5, function(data) {
    if(data.status === 0) {
        var bdPoint = data.points[0];
        // 使用转换后的坐标
    }
});
```

## 优势对比

### 百度地图 vs Leaflet（OpenStreetMap）

| 特性 | 百度地图 | Leaflet |
|------|---------|---------|
| 底图 | 百度地图 | OpenStreetMap |
| 中文支持 | ✅ 优秀 | ⚠️ 一般 |
| 国内数据 | ✅ 详细 | ⚠️ 较少 |
| 加载速度 | ✅ 快（国内） | ⚠️ 慢（国外服务器） |
| 需要密钥 | ✅ 需要 | ❌ 不需要 |
| 坐标系统 | BD-09 | WGS-84 |
| 免费额度 | 有限制 | 无限制 |

## 常见问题

### Q1: 地图不显示或CORS错误？
**解决方案：**
1. 使用本地服务器：运行 `python start_server.py` 或双击 `启动地图服务器.bat`
2. 不要直接双击HTML文件（会有CORS跨域问题）
3. 检查是否配置了正确的AK
4. 检查网络连接
5. 查看浏览器控制台错误信息

### Q2: 标记位置不准确？
- 可能需要坐标转换
- 检查原始数据的坐标系统
- 使用百度地图坐标拾取工具验证

### Q3: 超出配额限制？
- 百度地图API有免费配额限制
- 可以升级为付费版本
- 或者使用Leaflet版本（无限制）

### Q4: 如何修改标记样式？
在HTML文件中找到这段代码：
```javascript
var circle = new BMap.Circle(pt, 100, {
    strokeColor: 'white',
    strokeWeight: 1,
    strokeOpacity: 0.8,
    fillColor: color,
    fillOpacity: 0.6
});
```

可以修改：
- `100`：圆圈半径（米）
- `strokeColor`：边框颜色
- `fillColor`：填充颜色
- `fillOpacity`：透明度（0-1）
