# 百度地图等值线版本使用说明

## 🎯 版本特性

这是**百度地图 + 等值线边界**的完整版本，结合了两者的优势：

- ✅ 百度地图（国内访问快速）
- ✅ 等值线边界显示（彩色多边形）
- ✅ 客户点颜色区分
- ✅ 完整交互功能
- ✅ 支持百度坐标系

## 📍 坐标系统说明

### 你的数据坐标

根据你的 `client_data.json`，坐标格式为：
```json
{
  "lon": 112.9388,  // 经度
  "lat": 28.2282    // 纬度
}
```

这是**WGS84坐标系**（标准GPS坐标），百度地图会自动处理坐标转换。

### 坐标系对比

| 坐标系 | 说明 | 你的数据 | 百度地图 |
|--------|------|---------|---------|
| WGS84 | GPS标准坐标 | ✅ 是 | 自动转换 |
| GCJ02 | 国测局坐标（火星坐标） | ❌ 否 | 自动转换 |
| BD09 | 百度坐标 | ❌ 否 | 原生支持 |

**结论**: 你的数据是WGS84坐标，百度地图会自动转换，无需手动处理！

## 🔧 技术实现

### 百度地图多边形API

```javascript
// 创建多边形
const points = polygon.map(coord => new BMap.Point(coord[0], coord[1]));

const baiduPolygon = new BMap.Polygon(points, {
    strokeColor: color,      // 边框颜色
    strokeWeight: 2,         // 边框宽度
    strokeOpacity: 0.8,      // 边框透明度
    fillColor: color,        // 填充颜色
    fillOpacity: 0.2         // 填充透明度
});

map.addOverlay(baiduPolygon);
```

### 坐标处理

```javascript
// 后端返回的坐标格式：[[lon, lat], [lon, lat], ...]
// 直接转换为百度地图点（百度会自动处理坐标系转换）
const points = polygon.map(coord => new BMap.Point(coord[0], coord[1]));
```

## 🐛 常见问题

### Q1: 地图不显示
**原因**: 百度地图AK未配置或无效  
**解决**: 
1. 申请百度地图AK
2. 替换HTML中的 `YOUR_BAIDU_MAP_AK`
3. 检查AK是否启用了JavaScript API

### Q2: 等值线不显示
**原因**: 后端未返回多边形数据  
**解决**:
1. 检查浏览器控制台（F12）
2. 确认使用 `ContourBasedClusteringWithoutZ22_map.py`
3. 查看服务器日志

### Q3: 坐标位置不对
**原因**: 坐标系问题  
**解决**:
- 你的数据是WGS84坐标，百度会自动转换
- 如果位置偏移，检查数据是否正确
- 百度地图会自动处理坐标转换，无需手动处理

### Q4: 多边形形状奇怪
**原因**: 参数设置不合适  
**解决**:
- 调整 `grid_size` 参数（0.05 → 0.1）
- 增大 `max_buffer_distance`（5 → 10）
- 尝试不同参数组合

## 💡 使用建议

### 参数调优

1. **首次使用**: 使用默认参数
   - grid_size: 0.05
   - max_buffer_distance: 5
   - min_cluster_size: 10

2. **边界太复杂**: 增大 grid_size（0.05 → 0.1）

3. **簇太多**: 增大 max_buffer_distance（5 → 10）

4. **有很多小簇**: 增大 min_cluster_size（10 → 20）

### 最佳实践

1. ✅ 先用默认参数测试
2. ✅ 观察等值线边界形状
3. ✅ 根据业务需求调整参数
4. ✅ 对比不同参数的评价指标
5. ✅ 选择轮廓系数最高的参数组合
