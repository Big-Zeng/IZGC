# 交互式客户聚类分析系统

## 📋 系统简介

这是一个基于Web的交互式客户聚类分析系统，用户可以在浏览器中动态调整聚类参数，实时查看聚类结果和评价指标，并在百度地图上可视化展示。

## 🎯 核心功能

### 1. 交互式参数调整
- 网格大小 (grid_size): 0.01 - 0.2
- 最大缓冲距离 (max_buffer_distance): 1 - 20
- 最小簇大小 (min_cluster_size): 1 - 50

### 2. 实时聚类分析
- 使用 ContourBasedClusteringWithoutZ22 算法
- 非交互模式运行（不显示matplotlib窗口）
- 自动合并小簇
- 确保所有点都被分配（无噪声点）

### 3. 可视化展示
- 百度地图显示客户位置
- 不同颜色区分不同簇
- 点击查看客户详情
- 鼠标悬停显示客户名称
- 图例显示各簇信息

### 4. 评价指标
- 轮廓系数 (Silhouette Score)
- Calinski-Harabasz 指数
- Davies-Bouldin 指数
- 簇内误差平方和 (Inertia)
- 簇间距离统计

## 🚀 快速启动

### 1. 安装依赖
```bash
pip install flask flask-cors numpy scipy scikit-learn shapely matplotlib
```

### 2. 启动服务器

**Windows用户**:
```bash
双击运行: 启动交互式聚类服务.bat
```

**所有用户**:
```bash
cd map_visualization
python clustering_server.py
```

### 3. 访问系统
打开浏览器访问: **http://localhost:5000**

### 4. 测试系统（可选）
```bash
# 在另一个终端窗口运行
python test_server.py
```

## 🎨 界面说明

## 📊 使用流程

```

   ↓

   ↓
3. 等待计算（10-30秒）
   ↓
4. 查看地图上的聚类结果
   ↓
5. 查看评价指标
   ↓
```

## 🔧 技术架构

### 前端
- HTML5 + CSS3 + JavaScript
- 百度地图 JavaScript API v3.0
- Fetch API 进行异步请求

### 后端
- Flask Web框架
- Flask-CORS 处理跨域
- ContourBasedClusteringWithoutZ22 聚类算法

### 算法
- 等值线聚类 (Contour-Based Clustering)
- 基于密度的空间聚类
- 自动虚拟点生成
- 缓冲区扩展
- 小簇合并

### 评价
- Scikit-learn 评价指标
- SciPy 空间距离计算
- NumPy 数值计算

## 🐛 常见问题

### Q1: 服务器启动失败
**原因**: 缺少依赖包  
**解决**: `pip install flask flask-cors`

### Q2: 地图不显示
**原因**: 百度地图AK未配置或网络问题  
**解决**: 配置正确的AK，检查网络连接

### Q3: 聚类计算很慢
**原因**: grid_size 太小，计算量大  
**解决**: 增大 grid_size 参数（如 0.05 → 0.1）

### Q4: 端口被占用
**原因**: 5000端口已被其他程序使用  
**解决**: 修改 `clustering_server.py` 中的端口号

### Q5: CORS错误
**原因**: 跨域请求被阻止  
**解决**: 确保已安装 flask-cors 包
