# 零值点交互式聚类使用说明

## 功能概述

这是一个支持手动添加零值点的交互式聚类分析系统，主要功能包括：

1. **加载真实数据** - 支持加载长沙市等城市的坐标数据
2. **手动添加零值点** - 在地图上点击添加零值点，用于分割聚类区域
3. **保存零值点** - 将手动添加的零值点保存到CSV文件
4. **执行聚类** - 结合零值点执行等值线聚类算法
5. **可视化结果** - 在地图上显示聚类结果、等值线边界和零值点

## 启动服务

```bash
cd map_visualization
python start_zero_points_server.py
```

然后在浏览器中访问: http://localhost:5001

## 使用步骤

### 1. 加载数据
- 从下拉菜单选择数据集（如"长沙市"）
- 点击"加载数据"按钮
- 地图会自动调整视野显示所有数据点

### 2. 添加零值点
- 点击"切换到添加零值点模式"按钮
- 此时鼠标变为十字准星
- 在地图上点击即可添加零值点（显示为绿色圆点）
- 零值点会自动添加到列表中

### 3. 管理零值点
- **删除单个**: 点击零值点弹出框中的"删除"按钮，或点击列表中的"×"
- **清空所有**: 点击"清空"按钮
- **保存**: 点击"保存"按钮，零值点会保存到 `data/real_data/{数据集名}_zero_points.csv`

### 4. 执行聚类
- 调整聚类参数：
  - **网格大小**: 值越小，网格越密集，聚类越精细
  - **最大缓冲距离**: 扩展缓冲区的最大步数
  - **最小簇大小**: 小于此值的簇会被处理
  - **小簇合并**: 勾选则合并到大簇，否则标记为噪声
- 点击"开始聚类"按钮

### 5. 查看结果
- 数据点会按簇着色
- 等值线边界会显示为半透明多边形
- 零值点保持绿色显示
- 右下角图例显示各簇信息
- 左侧面板显示聚类指标（轮廓系数、CH指数等）

## 零值点的作用

零值点（z=0的虚拟点）用于在等值线聚类中创建"分割线"：

- 在两个密集区域之间添加零值点，可以将它们分割成不同的簇
- 零值点会影响等值线的生成，从而影响聚类边界
- 适合用于手动调整聚类结果，分割过大的簇

## 文件说明

- `clustering_server_with_zero_points.py` - Flask服务器
- `interactive_clustering_with_zero_points.html` - 前端页面
- `start_zero_points_server.py` - 启动脚本
- `data/real_data/{城市}_zero_points.csv` - 保存的零值点文件

## 注意事项

1. 确保已安装依赖: `pip install flask flask-cors pandas numpy scipy scikit-learn shapely`
2. 数据文件应放在 `data/real_data/` 目录下
3. 零值点文件会自动加载（如果存在）
4. 端口5001，如有冲突可在代码中修改
